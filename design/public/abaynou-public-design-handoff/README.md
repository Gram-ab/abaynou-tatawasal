# Abaynou Tatawasal Public Design Handoff

This package is the implementation source of truth for the approved public-side visual direction.

Start with:

1. `PUBLIC_DESIGN_SPEC.md`
2. `CODEX_IMPLEMENTATION_BRIEF.md`
3. `design-tokens.json`
4. `assets/ASSET_MANIFEST.md`

`reference-source/` contains the approved prototype source for visual comparison only. Its demo content and behaviors do not override the frozen functional decisions in `PUBLIC_DESIGN_SPEC.md`.

The current approved Arabic font is **IBM Plex Sans Arabic**, not the older Noto Sans Arabic note found in an earlier prototype instruction file.
